# German (de) curriculum plan: lessons 1-30

Standard German (Hochdeutsch, Germany), du in friendly talk and Sie in service situations. Level A1 to A2 (not B1). Each lesson = one situation + one grammar point, reusing earlier grammar in the dialogue. Levels: orders 1-6 beginner, 7-20 elementary, 21-30 intermediate (same as the French path). Beta (not native-reviewed).

Pronunciation guide (`translit`): English-style respelling in syllables, STRESSED SYLLABLE IN CAPITALS. Fixed key: ü = ew, ö = ur, ä = eh (or ay for long), ie = ee, ei = eye, eu/äu = oy, ch after e/i = ç, ch after a/o/u = kh, ß and ss = s, z = ts, w = v, v = f, sp/st at the start = shp/sht, final b/d/g = p/t/k, r is a throat r (write r).
