# Tagalog (tl) curriculum plan: lessons 1-30

Standard Tagalog / Filipino as spoken in Metro Manila, with the polite particles po and opo. Level A1 to A2 (not B1). Each lesson = one situation + one grammar point, reusing earlier grammar. Levels: orders 1-6 beginner, 7-20 elementary, 21-30 intermediate. Beta (not native-reviewed). Use standard modern Filipino spelling (e.g. "kumusta", "pwede" accepted; use the form most learners meet and say it in the hint when two spellings exist). Write the common everyday forms, not deep or old-fashioned words.

Pronunciation guide (`translit`): Tagalog spelling is close to sound, so use syllables split with hyphens and the STRESSED SYLLABLE IN CAPITALS (ku-MUS-ta). Mark the glottal stop at the end of a word with an apostrophe-free hint in `hint` only when it matters (for example "ma-ga-NDA" is not needed). ng = as in "sing" (write ng), a single g after n, as in "ngayon" = nga-YON. The Spanish-style r is a tapped r.
